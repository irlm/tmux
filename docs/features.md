# Features and Project Layout

## What This Repo Owns

This repository is the tmux and terminal side of the environment. It includes:

- tmux configuration in `tmux.conf`
- installer scripts for macOS, Linux, and Windows
- helper scripts for popups, search, notes, prompts, and status bar segments
- shell-oriented quality-of-life setup

Helix is the managed editor (`helix/config.toml`); the optional Neovim configuration lives in a separate repo: [irlm/nvim](https://github.com/irlm/nvim).

## Main Features

### Tmux Workflow

- `C-a` prefix instead of `C-b`
- vim-style pane movement with `h j k l`
- popup-driven workflow for `lazygit`, `lazydocker`, system info, notes, and search
- session and window helpers for switching, renaming, detaching, and remote work

### Editor Integration

- Helix with this repo's review keys: `-a` sends the selection to the agent pane, `-f` opens a `file:line` from the pane, `-g` lazygit, `]c` next change
- `C-a C-f` picks any `file:line` the pane mentions and opens it in `$EDITOR`
- lazygit diffs through `delta` when installed (syntax colours, line numbers)
- optional Neovim (`--nvim`); `ctrl+hjkl` reach into it from tmux and Herdr alike
- installer scripts clone both repos together
- markdown preview: inline rendering (`Space mr`) and live browser preview (`Space mp`)

### Status Bar

The right side of the tmux status bar is generated by `scripts/status_right.sh`. It pulls together:

- network speed
- CPU usage
- RAM usage
- battery status when available
- current time

The left side shows the session name, current git branch when present, and sync state. A second line appears under the bar while the active pane holds an ssh session, naming the host, user and port. While a remote tmux is in front it switches to a `REMOTE` indicator, meaning the local prefix is off and keys are going to the server.

### Session Persistence

The config includes:

- `tmux-resurrect` for save and restore
- `tmux-continuum` for periodic autosave and optional restore

Pane contents are also captured for restore support.

### Search and Reference Helpers

The repo includes popup helpers for:

- web search
- quick AI questions
- `cheat.sh`
- `tldr`
- man pages

## Plugin Stack

Only session persistence is a plugin:

- `tmux-plugins/tpm`
- `tmux-plugins/tmux-resurrect`
- `tmux-plugins/tmux-continuum`

Copy mode copies through `scripts/clipboard.sh` (pbcopy, wl-copy, xclip, xsel,
clip.exe or OSC 52), `ctrl+hjkl` navigation is a few lines in `tmux.conf`
that hand the key to Neovim when it runs in the pane, `C-a Space` and `C-a u`
are `scripts/pick.sh`, the status readings come from `scripts/status_right.sh`
and the theme from `scripts/appearance.py`. Nothing needs compiling.

## Script Layout

| Script | Purpose |
|--------|---------|
| `scripts/sessionizer.sh` | project switcher / session picker |
| `scripts/notes.sh` | quick notes popup |
| `scripts/websearch.sh` | search UI inside tmux |
| `scripts/websearch_fetch.py` | fetch helper for search results |
| `scripts/ai-ask.sh` | quick AI prompt popup |
| `scripts/status_right.sh` | right side status bar renderer |
| `scripts/net_speed.sh` | network speed helper |

| `scripts/status_ssh.sh` | second status line while the active pane holds an ssh session: `SSH host as user:port` |
| `scripts/ssh-remote.sh` | `C-a s` / `C-a P`: connect, install the config on the server if missing, attach its tmux (new window / split pane) |
| `scripts/remote-mode.sh` | decides whether the pane in front shows a remote tmux and switches the local prefix off or on accordingly; `F12` overrides it |
| `scripts/prompt.sh` | lightweight bash prompt |
| `scripts/prompt.zsh` | lightweight zsh prompt |
| `scripts/herdr-config.sh` | render, validate and install the Herdr config and plugin |
| `scripts/herdr-config.ps1` | the same on Windows, with the popups through Git Bash or WSL |
| `scripts/status_right.ps1` | the tab bar readings on Windows: network, CPU, memory, battery |
| `scripts/herdr-navigate.sh` | `ctrl+hjkl` under Herdr: into Neovim when it runs in the pane, else focus the next pane |
| `scripts/pick.sh` | pick text to copy or a URL to open from the pane behind the popup |
| `scripts/llm_usage.py` | `C-a $`: tokens by day and model for Claude Code and Codex, plus live limits |

## Reliability and Customization

See [Customization and diagnostics](customization.md) for local overrides, desktop/server/compact profiles, ASCII mode, the `C-a F` command palette, worktree-aware project selection, read-only diagnostics, and regression tests. `actions.tsv` drives popup bindings and generated action help; `tools.tsv` defines required tools by profile.

Status sampling uses private atomic caches. Battery samples are reused for a minute; SSH status is session-scoped. Starting tmux does not clone plugins or require network access.
